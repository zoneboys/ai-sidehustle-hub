🛡️ 投递前必读：职位真伪鉴别指南（点开看 8 条铁律）
  • 先交钱 = 骗局。正规雇主永远不会向求职者收钱。凡是要「培训费/服装费/押金/保证金/激活费」的，直接拉黑。
  • 官网核验公司与 HR。搜公司官网 + LinkedIn / 企查查确认公司与岗位真实存在；HR 邮箱域名应与公司一致，用免费邮箱（@gmail/@163）自称 HR 的多为假。
  • 超高薪 + 零要求 = 钩子。「日结 500、在家点点鼠标、无经验月入过万」是刷单/杀猪盘的标准开场白。
  • 索要身份证、银行卡、验证码的立即停止。正规流程只在签合同后需要有限信息，任何提前索要敏感信息的都是诈骗。
  • 拉群做任务、下载非官方 App = 诈骗。让你先垫付「刷单返利」的，本金必被吞。
  • 面试流程异常要警惕。不发 JD、不视频面试、直接发 offer、催你立刻决定的，正规公司不会跳过流程。
  • 跨境远程岗查三样。公司官网、Glassdoor/脉脉评价、合同主体；拒绝签书面合同的远程岗不要做。
  • 善用本站原帖链接。下方职位均来自 Remotive / WWR / Remote OK / Jobicy / HN 等正规职位板，点卡片「直达原帖」核对职位描述、薪资与发布日期是否一致，被篡改的多半有问题。

ℹ️ 关于本站

🔄 每日自动更新是怎么实现的？

本站是纯静态网页（单文件 index.html），数据层由三部分组成：
1️⃣ 静态精选库 —— 来自两大开源仓库的人工精选数据，内置于页面中；
2️⃣ 每日抓取脚本 —— scripts/fetch-jobs.mjs 定时调用 Remotive、We Work Remotely、Hacker News「Who is hiring?」等公开 API / RSS，抓取最新远程职位，写入 data/daily-updates.json；
3️⃣ GitHub Actions 定时任务 —— 每天北京时间上午自动运行抓取脚本并提交数据，网站每日打开即可读到最新内容。
部署到 GitHub Pages / Vercel / Cloudflare Pages 后，无需服务器即可享受每日更新。
